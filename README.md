### Hi, I'm Babu Annamalai 👋

Open-source maintainer and writer, based in Bengaluru, India. I'm a core member of the [JasperFx Critter Stack](https://jasperfx.net) ([Marten](https://martendb.io), Wolverine and friends), build .NET libraries and tools with millions of NuGet downloads, and write about .NET, PostgreSQL and AI tooling at **[mysticmind.dev](https://mysticmind.dev)**. Founder and partner at [Radarleaf Technologies](https://radarleaf.com) (consulting and bespoke software).
